Altcraft Flutter SDK is a library for interacting with the **Altcraft Marketing Platform**. The **Profile** package is one of its modular components.

---

## Profile

The profile module is responsible for user profile fields.

- [x] Updating profile fields from the app.
- [x] Native event message catalog (`moduleEvents`).

---

## Dependencies

Add the **Profile** package to your Flutter application's `pubspec.yaml`:

```yaml
dependencies:
  altcraft_profile: ^1.0.0
```

The Core package is included automatically as a dependency.

---

## Requirements

- Flutter 3.27+ (Dart 3.6+).
- Android 7.1+ (API 25).
- iOS 13.0+.
