# altcraft_sdk_example

Example application demonstrating the Altcraft SDK Flutter plugin.

## Running the Example

```bash
flutter pub get
flutter run
```

## What It Shows

- SDK initialization with configuration
- Push subscription management (subscribe, suspend, unsubscribe)
- Token retrieval and provider switching
- Mobile event sending
- Profile field updates
- Real-time SDK event stream
- Configuration management with persistent storage

## Screens

|------|------|--------|---------|
| Push data, actions, events | SDK event log | API URL, providers | Push subscribe options |

## Requirements

- Flutter >=3.27.0
- Dart >=3.0.0
- Android minSdk 21
- iOS 13.0+
